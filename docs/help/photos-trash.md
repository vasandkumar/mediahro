# Recently deleted

**Delete** (viewer ⋮ menu, or **More → Delete** on a selection) moves photos to **Albums → Recently deleted** instead of erasing them.

- Photos stay there for **30 days**, up to 2 GB together; when it is full the oldest go first.
- Open **Recently deleted**, tap photos to select them, then **Restore** (they go back where they were; if that name is taken again they come back with `_restored` added) or **Delete for good**. **Empty** removes everything.
- **Undo** in the message after a delete restores them at once.
- A single file larger than 1 GB does not fit the bin; it goes to the system trash instead (Android's trash keeps it for 30 days too).
- The bin keeps a copy of each file inside Mediahro's own storage and removes the original from its folder, so a photo that cannot be removed from its source (a read-only share, for example) is reported and left where it is.
