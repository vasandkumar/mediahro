# Reading and translating subtitles

## Read subtitles aloud

Turn on **Subtitles → Read subtitles aloud** and each subtitle line is spoken with your device's voice as it appears, in the subtitles' language. A new line interrupts the previous one, so the voice never falls behind the video. Nothing is spoken while the video is paused. The speaking speed follows your system setting; **Settings → Subtitles** can make it faster or slower.

## Translate subtitles

**Subtitles → Translate subtitles** translates the subtitles you are watching into another language and adds the result as a new track, named for example "Deutsch (translated)".

- Translation runs **on your device** with the translation built into the system (Apple Translation on iPhone, iPad and Mac, Google ML Kit on Android, Windows translation where available). Your subtitles are never sent anywhere.
- The first time you translate between two languages, the system may need to download a language pack. Mediahro asks before it downloads anything.
- The languages offered are the ones your device can translate.

## Subtitle files only, for now

Both features work with subtitle files: files next to the video, files you added, and subtitles you saved in the editor. Subtitles built into the video file are not supported yet; this is planned.
