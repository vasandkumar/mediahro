# Internet radio

The **Radio** tab on the Music screen holds the stations you add. Mediahro has no built-in station directory: you add the stream address of a station you already listen to.

## Adding stations

- **Add station** asks for the stream address (for example `https://stream.example.com/live`) and a name. If you leave the name empty, the host name is used.
- **Import** reads a station list in M3U or PLS format. Only internet addresses are imported; local files and duplicates are skipped.
- **Export** saves all your stations as an M3U file you can open in other players or import again later.

Open a station's menu (⋮) to mark it as a favourite, edit it or delete it. Favourites are listed first.

## Listening

Tap a station to play it. Now Playing and the mini player show a **Live** badge instead of a seek bar, and skip buttons do nothing while a station plays. The lock screen, notification and headset controls play and pause the station.

Playing a song from your library returns to your queue where you left it.

Pausing a station for a while closes the stream; pressing play again reconnects to the live broadcast.
