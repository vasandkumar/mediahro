# Audiobookshelf

If you run an Audiobookshelf server, Mediahro can browse it and play from it. Nothing is sent anywhere but to your own server.

## Connecting

Add the server under **Sources → Media server → Audiobookshelf** (address, user name, password). Once one is connected, an **Audiobookshelf** tab appears in Music.

## Browsing and playing

- **Continue listening** shows what you were in the middle of on any connected server.
- Under each server are its libraries. A library lists its books a page at a time; a podcast library lists shows, and a show lists its episodes. Search looks across the server.
- Open a book to see who wrote and read it, its length and description. **Play** (or **Resume at …**) starts it. A finished book starts from the beginning.
- The player has chapters (read from the file), back 10 and forward 30 seconds, speed and skip silence, a sleep timer and show notes. Each item remembers its own speed and silence setting.

## Your place stays on the server

Mediahro tells the server where you are about every 30 seconds, when you pause or jump, and when you finish, so Audiobookshelf's other apps and the web player pick up from the same place. If the server can't be reached when you pause, Mediahro keeps your place and tells the server next time; until then it is your device's place that counts. If another device listened in the meantime, the server's place wins.

## Offline copies

**Download** on a book keeps a copy on the device (a download like any other: resumable, within the size limit on the Downloads screen). Mediahro plays the copy when there is one, even without a connection. **Remove download** deletes it.

## Mark as finished

**Mark as finished** and **Mark as not finished** set the state on the server too.
