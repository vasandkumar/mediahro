# Editing subtitles

In the player, open **Subtitles → Edit subtitles**. If the video has several subtitle files, choose one; if it has none, pick a file. The editor opens next to the playing video, so you can check your changes as you go.

## Fixing the timing

- **Shift all** moves every subtitle earlier or later. Select some subtitles first (the box at the start of each line, or touch and hold) to move only those.
- **Resync by two points** fixes subtitles that start right but drift. Select one subtitle near the start and one near the end, then enter when each should start. **Now** fills in the video's current time. Everything in between is adjusted to match.
- **Subtitle speed** converts subtitles made for another frame rate, for example from 23.976 to 25 fps.
- **Fix overlaps** shortens subtitles that run into the next one.

## Changing the text

Tap a subtitle to change its text, start and end. On Android, iPhone and iPad, spelling mistakes are underlined by the system spell checker. **Add here** and **Split here** work at the video's current time; **Merge** joins the selected subtitles; **Delete** removes them. Undo and redo are at the top.

## Wrong characters

If letters look wrong, choose **Fix encoding** and the file's encoding, for example **Cyrillic (Windows-1251)**. The file is read again with that encoding.

## Saving

**Save** (the disk button) saves as SRT, ASS or WebVTT, in UTF-8. The file goes next to the original when that folder can be written: on the device, in a folder you added, or on a writable network share. Otherwise it goes to Mediahro's subtitle folder. The saved subtitles are shown in the player straight away.
