# Places and locations

Photos are grouped by the place they were taken. There is no map: Mediahro does not download map pictures, so nothing about where you take photos ever leaves your device.

## Place names

Places are found on your device from a bundled list of cities with at least 15,000 people (data from GeoNames, CC BY 4.0). The **Places** tab groups photos that carry a GPS position by country and city; the details sheet of a photo shows the nearest city.

## Setting or removing a location

- **One photo:** Details → **Edit details** → **Search or type a location**. Search for a city, or type latitude and longitude in decimal degrees (`48.8566, 2.3522`, or with letters: `33.8688 S 151.2093 E`), then **Use this location**.
- **Several photos:** select them, then **More → Set location** (the same chooser) or **Remove location**. Mediahro writes the position into each file (or a small `.xmp` file next to camera RAW files). A file it cannot write to is reported; the others are still changed. Videos are skipped.
