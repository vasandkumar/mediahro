# Keyboard shortcuts

Mediahro works fully from the keyboard on computers, on iPad with a hardware keyboard, and on Android with a keyboard attached.

Press **?** at any time to see every shortcut. In that list, **Copy as text** copies a plain-text version you can paste or print. On a Mac, ⌘ replaces Ctrl.

## Default keys

| Key | Action |
|---|---|
| ? | Show keyboard shortcuts |
| Ctrl+, | Open settings |
| Ctrl+O / Ctrl+U | Open a file / open a URL |
| Ctrl+F | Search |
| Ctrl+1 / 2 / 3 | Go to Video / Music / Photos |
| Space or K | Play or pause |
| ← → | Back or forward 5 seconds (Shift: 1 second, Ctrl: 1 minute) |
| J / L | Back or forward 10 seconds |
| 1–9 | Jump to 10 %–90 % |
| , . | Previous or next frame |
| B / N | Set or clear an A-B loop |
| [ ] | Slower or faster; Backspace returns to normal speed |
| ↑ ↓ | Volume up or down |
| M | Mute |
| A | Next audio track |
| C / V | Audio delay −10 ms / +10 ms |
| S | Next subtitle track; Shift+S turns subtitles on or off |
| Z / X | Subtitle delay −50 ms / +50 ms |
| F / Esc | Full screen / exit full screen (also F11 on Windows, ⌃⌘F on a Mac) |
| I | Playback information |
| P | Picture in picture |
| T | Keep on top |
| Ctrl+S | Take a screenshot |

## Change a shortcut

1. Open **Settings → Keyboard shortcuts**.
2. Choose an action and press the new key combination.
3. If another action already uses that key, Mediahro tells you which one. **Replace** moves the key to the new action.

In the same window, **Remove key** leaves the action without a key, and **Restore default** brings back the original. **Restore all defaults** at the top resets every shortcut. If two actions ever end up sharing a key, a warning at the top of the list says how many keys clash.

Typing in a text field, such as search, never triggers a shortcut.
