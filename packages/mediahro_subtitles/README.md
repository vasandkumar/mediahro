# mediahro_subtitles

Text-subtitle parsers and writers (SRT, WebVTT, ASS/SSA, SMI, MicroDVD, TTML, LRC, TXT), charset detection glue, the subtitle editor model, audio-based auto-sync, OCR and auto-caption pipelines. Parsing runs in isolates with `ParseLimits` (PRIV-005) and is fuzzed nightly. Owner: lane C1.
